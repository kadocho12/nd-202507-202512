# Select and Speak

## 使い方

1. クローンします。
2. クローンしたフォルダを[chrome://extensions/](chrome://extensions/)に追加します。この時、デベロッパーモードをONにしてください。
3. Chrome拡張機能リストの中からSelect and Speakをピン留めします。
4. Select and Speakをのアイコンをクリックします。
5. 有効化をONにします。
6. Webページ内のテキストをマウスで選択します。選択したテキストが読み上げられます。
7. 使い終わったら有効化をOFFにします。

## Tips

- 速度と音量を調整できます。
- 読み上げ途中に設定を変更すると即時反映されます。
